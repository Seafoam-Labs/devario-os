# Devario keyring package

An empty `devario-revoked` list contains one LF newline so Remora accepts it
as an uploaded source file. It still declares no revoked keys. Preserve its
bytes and the matching checksum in `PKGBUILD` and `.SRCINFO`; upload the whole
recipe directory together rather than editing source checksums on the worker.

The public bundle, trust, revocation, and single `active-signer` selection are
generated by `scripts/init-repository-key.sh`. Multiple trusted primary public
keys may coexist during a rotation, but only the fingerprint in
`active-signer` may sign newly built repository content. Only public material
is packaged. Never place a production secret key in this directory or in the
source tree.
